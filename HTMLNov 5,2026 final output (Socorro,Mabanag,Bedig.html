Introduction to Computing

Computing is the process of using computer technology to complete a given goal-oriented task. It includes designing and building hardware and software systems, processing and managing information, scientific research, artificial intelligence, and creating communications & entertainment media.

Key Insight

Computing is far more than programming — it is the entire spectrum of activities that make computers useful to people and organizations.

🖥️

Hardware

Physical components: CPU, memory, storage, input/output devices.

💾

Software

Programs and instructions that control the hardware.

📡

Networking

Connecting devices to share data and resources.

🧠

Data & Knowledge

Turning raw data into useful information and knowledge.

Characteristics of a Computer

Speed

Performs millions to billions of operations every second.

Accuracy

Extremely high accuracy when programmed correctly.

Diligence

Works continuously without fatigue or loss of concentration.

Storage Capacity

Can store and retrieve vast amounts of data quickly.

Versatility

Can perform almost any task depending on the software.

Automation

Once programmed, executes tasks with minimal human help.

History of Computing

~2400 BCE

Abacus

Earliest calculating tool using beads on rods.

1837

Analytical Engine – Charles Babbage

First design of a general-purpose mechanical computer. Ada Lovelace writes the first algorithm.

1936

Turing Machine – Alan Turing

Theoretical foundation of modern computing.

1941

Z3 – Konrad Zuse

World’s first working programmable digital computer.

1945–46

ENIAC & Von Neumann Architecture

First general-purpose electronic computer. Stored-program concept is born.

1970s–80s

The PC Revolution

Apple II, IBM PC and Windows bring computers into homes and small businesses.

1990s

World Wide Web & E-Commerce

Tim Berners-Lee invents the WWW. Online shopping and global communication explode.

2000s–Now

Mobile, Cloud & AI

Smartphones, cloud computing and artificial intelligence become everyday technology.

Information Systems

An Information System is a set of components that collect, process, store and distribute information to support decision-making and control in an organization.

Components of an Information System

🔧

Hardware

Computers, servers, storage, networking devices.

📀

Software

Operating systems and application programs.

🗄️

Data / Databases

Organized facts that the system processes.

🌐

Networks

Wired or wireless connections between devices.

👥

People

Users, developers, managers and support staff.

📋

Procedures

Rules and methods that govern system use.

Role of Information Systems

They improve efficiency, support decisions at operational, tactical and strategic levels, create competitive advantage, enable communication and help organizations adapt to change.

CPU / Processor / Microprocessor

The Central Processing Unit is the “brain” of the computer. A microprocessor is a complete CPU on a single chip.

⚙️

Control Unit

Fetches and decodes instructions, directs the whole processor.

🔢

ALU

Performs arithmetic and logical operations.

📦

Registers

Tiny ultra-fast storage inside the CPU.

⏱️

Clock

Provides the timing signal (measured in GHz).

Important Metrics

Clock speed • Number of cores • Threads • Cache size (L1/L2/L3) • Architecture (x86-64, ARM, RISC-V)

Computer Memory

Primary Memory

⚡

RAM

Volatile read/write memory. Holds running programs and data. (DDR4, DDR5)

📖

ROM

Non-volatile. Stores firmware (BIOS/UEFI). Types: PROM, EPROM, Flash.

💾

Cache

Very fast memory inside/near the CPU (L1, L2, L3).

Computer Languages and Their Types

1️⃣

Machine Language

Pure binary (0s and 1s). Fastest but almost impossible for humans to write.

2️⃣

Assembly Language

Uses mnemonics (MOV, ADD). Needs an assembler. Still hardware-specific.

3️⃣

High-Level Languages

Python, Java, C++, JavaScript, C#. Easy to read and portable.

4️⃣

4th Generation (4GL)

Closer to natural language. Example: SQL for databases.

Translators

Compiler – translates whole program at once • Interpreter – line by line • Assembler – assembly → machine code

Introduction to Databases

A database is an organized collection of data. A Database Management System (DBMS) lets users create, store, retrieve and manage that data efficiently.

Table

Rows (records) and columns (fields).

Primary Key

Unique identifier for each record.

Foreign Key

Links one table to another.

SQL

Standard language for querying relational databases.

Common Types

Relational (MySQL, PostgreSQL) • NoSQL (MongoDB, Redis) • Cloud databases • In-memory databases

Data Communication & Networking

Data communication is the exchange of data between devices through a transmission medium following a set of rules (protocol).

Modes of Communication

➡️

Simplex

One-way only. Sender → Receiver. Examples: TV broadcast, radio, keyboard to computer.

↔️

Half-Duplex

Two-way but one at a time. Walkie-talkies, older Ethernet hubs.

🔄

Full-Duplex

Two-way at the same time. Modern telephone, switched Ethernet, video calls.

Network Topology

TopologyDescriptionAdvantagesDisadvantages
BusAll devices share one backbone cableSimple & cheapSingle point of failure
StarAll devices connect to a central switchEasy to manage, cable failure isolatedCentral device is critical
RingDevices form a closed loopOrderly accessBreak can disable network
MeshMany or all devices interconnectVery fault-tolerantExpensive & complex
TreeHierarchical starsScalableRoot failure partitions network
HybridCombination of topologiesFlexibleCan be complex

Internet & World Wide Web

Connecting to the Internet

You need an Internet Service Provider (ISP), a modem/router, and a device with a network interface. Common methods: Fiber, Cable, DSL, 4G/5G Mobile, Satellite, Wi-Fi.

How Data Travels the Internet

Data is broken into packets. Each packet contains the payload, source & destination IP addresses, sequence numbers and error-checking info. Packets travel through multiple routers using the TCP/IP protocol suite and are reassembled at the destination.
